# TT Brasil Burger Branding

Crie um site site institucional sobre a hamburgueria TT Brasil , com as seguintes diretrizes de design e código:
Direção visual (fuja do padrão genérico de IA):
Não use o layout clichê "hero centralizado + título grande + botão roxo/azul gradiente + 3 cards com ícone".
Escolha uma paleta de cores autoral e específica ao tema (nada de azul/roxo genérico de SaaS). Use no máximo 2-3 cores principais + neutros.
Use tipografia com personalidade: combine uma fonte serifada ou display marcante para títulos com uma sans-serif limpa para o corpo. Evite Inter/Roboto puro sem nenhum ajuste.
Quebre a grade simétrica às vezes: elementos assimétricos, sobreposições, espaços em branco generosos e não uniformes.
Use imagens/ilustrações com estilo consistente (evite ícones genéricos de biblioteca sem edição).
Animação na primeira dobra (hero):
Crie uma animação de entrada na página inicial usando CSS/JS (ex: texto que aparece com stagger, elementos que fazem parallax sutil no scroll, gradiente animado, partículas leves, ou um elemento SVG animado relacionado ao tema).
Use scroll-triggered animations (ex: com Intersection Observer ou GSAP/Framer Motion) para elementos que entram conforme o usuário rola a página.
Adicione microinterações: hover states com transições suaves, cursor customizado (opcional), botões com feedback tátil.
Responsividade:
Mobile-first, com breakpoints testados para celular, tablet e desktop.
Menu mobile bem pensado (não só um hambúrguer genérico — pense na transição/abertura).
Técnico:
Use bibliotecas leves via CDN se precisar de animação mais robusta (ex: GSAP para scroll animations).
